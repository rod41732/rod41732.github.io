# Hello from sub folder

let's embed some image

- a common pattern is storing image in `/assets/` folder, then refer to it 
    - it has no special meaning, Jekyll will simply serve the path as is
<img src="/assets/test-image.png"/>

- let's also add CSS `<link rel="stylesheet" href="/assets/weird-style.css"/>`

<link rel="stylesheet" href="/assets/weird-style.css"/>

<div id="test-style"> 
    this div will be styled by CSS
</div>

- Nothing stops you from using JS `<script type="text/javascript" src="/assets/example.js"></script>`
    - NOTE: due to behavior of JS, if you put the script tag before the element, then do something like `document.getElementById("...").addEventListener(...)` then, it will error if "cannot read property of null"  
    

<script type="text/javascript" src="/assets/example.js"></script>

<button id="test-button"> Test </button>

- Embedding liquid? 
    - example from: https://jekyllrb.com/docs/posts/
    
- `site` is a variable containing "whole site"
    - site.posts
    - site.tags

<ul>
  {% for post in site.posts %}
    <li>
      <a href="{{ post.url }}">{{ post.title }}</a>
    </li>
  {% endfor %}
</ul>

- tags: https://jekyllrb.com/docs/posts/

{% for tag in site.tags %}
  <h3>{{ tag[0] }}</h3>
  <ul>
    {% for post in tag[1] %}
      <li><a href="{{ post.url }}">{{ post.title }}</a></li>
    {% endfor %}
  </ul>
{% endfor %}
